90K / 120 DAYS TARGET TRACKER

Files:
- index.html
- style.css
- script.js

How to use:
1. Open index.html in Chrome.
2. Enter your daily income and press Add Income.
3. The website calculates collected, remaining, days left, required daily amount and progress automatically.
4. Data is saved in the browser using localStorage, so no money is deposited or transferred.
5. Use the ↻ button to reset all entries.

Target: Rs 90,000
Duration: 120 days
Starting daily requirement: Rs 750
